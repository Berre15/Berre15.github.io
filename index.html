NOVA Cinematic Studio

NOVA Cinematic Studio is a private tool run by Bert Pauwels (Belgium). It produces original short videos (book trailers, small game simulations, satisfying simulations and an original animated story) and uploads them to the owner's own YouTube channel, Bert Pauwels Books.

The tool uses the YouTube Data API only to upload videos to that one channel and to read the public statistics of those videos. It does not offer accounts to the public and does not access anyone else's YouTube data.
